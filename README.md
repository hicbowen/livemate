# 播伴（livemate）

播伴是一个本地优先的主播运营管理桌面应用。它把主播档案、直播场次、事实复盘、问题、改进方案、跟进记录和阶段目标串成一条可追溯的运营闭环，并为后续 AI 辅助预留结构化数据基础。

## 开发与构建

```powershell
npm --prefix frontend install
wails3 dev
wails3 build
```

前端也可以单独检查：

```powershell
npm --prefix frontend run build
```

## 数据位置

运行时数据默认保存在操作系统用户配置目录下的 `livemate` 子目录中，包含：

- `livemate.db`：SQLite 数据库
- `config.json`：本地配置
- `logs/`：应用日志
- `backups/`：导出的备份

具体绝对路径可在「设置」页查看。备份 ZIP 包含数据库、配置和清单；导入前会自动备份当前数据，并校验数据库完整性。

## 当前闭环

主播档案 → 直播记录 → 运营复盘 → 问题 → 一个或多个改进方案 → 跟进 / 效果 / 下一步动作。

日常录入可从「每日数据」进入：按日期展示全部在册主播，支持 Tab / Enter、整列或区域粘贴，以及只保存有数据的批量提交；「导入文件」提供 CSV / TSV 的字段映射、预览、逐行校验和确认导入，异常行会被明确跳过。主播详情页继续承载完整场次录入、复制上一场、复盘、问题、方案、跟进和时间线；趋势页提供 7 / 14 / 30 天窗口、周期对比，方案跟进提供实施前后场次对比。规则提示使用“可能异常”措辞，运营可以忽略、继续观察或转为问题。

应用不依赖云端同步，也不会在 MVP 阶段拉取平台 API 或把 AI 作为核心流程。未知指标保持为空，金额以整数分保存，主播删除采用归档而不是物理删除。
